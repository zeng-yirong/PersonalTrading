# PersonalTrading

> **AI for Trade** —— 新一代的 AI 投资交易助手。
> 一个人、一台机器，把「研究 → 判断 → 验证 → 进化」做成闭环。

常见的 AI 炒股工具止步于「给你一段听起来很有道理的回答」。PersonalTrading 想做的是另一件事：**让结论可追责、可验证、可改进**——每个数字能指回某个交易日，每个判断会被事后打分，每次打分又能反过来改进技能、因子与策略。

目前它以一个**本地运行的个人投研工作台**形态存在：面向 A 股 / ETF，数据与笔记不出本机，单机即可跑完研究、决策、复盘的全流程。

它由三块拼图组成：

1. **个人研究**：把一只股票的行情、基本面、资金、事件摆到同一张桌上，由 7 位 AI 分析师辩论出一个带目标价、止损与仓位的结论；
2. **主题研究**：把整个市场打成一份快照，回答「白酒还能不能拿」「市场情绪现在什么位置」这类没有单一标的的问题；
3. **自进化**：让技能、记忆、因子、策略都变成可以被证伪、晋级和淘汰的对象——这是它与「一次性问答」式 AI 工具的根本区别。

三块拼图之外，还有一条把它们串起来的**验证闭环**：结论落成模拟持仓，按 T+5 / T+20 打分，打分结果再回流到技能与策略。

---

## 适合谁

- 想用 AI 做**研究**、而不是要 AI 给一串代码的人；
- 愿意用数据验证观点的人：复权、as-of（不用未来信息）、费用、涨跌停约束都愿意搞清楚；
- 想把研究长期积累下来的人：每次推演、每条策略、每个因子都留档，几个月后能回头判断当时谁对。

## 核心特点

### 一、个人研究：一只票，七个视角

不是一次问答，而是一条有对抗的流水线：

```
7 位分析师（市场 / 基本面 / 资金面 / 热度舆情 / 事件驱动 / 大盘 / 板块）
        → 多空辩论 → 研究主管 → 交易员 → 三方风控 → 风控负责人裁定
```

- 分析师各看各的数据，互不通气；多空双方要互相反驳、并给出**证伪条件**；
- 交易员必须给目标价与止损，**期望收益、下行风险、赔率由代码按收盘价计算**，不允许模型自己写百分比；
- 风控三方从激进 / 中性 / 保守三个立场挑漏洞，负责人给最终裁定与仓位；
- 报告带**决策体检**：目标价低于现价、止损高于现价、仓位越界、否决却给仓位等矛盾会被逐条列出。

单次成本约 4.5–6.5 万 tokens、2–3 分钟，全程流式输出，节点一完成就出现。

### 二、主题研究：一句话问市场

- 大盘 / 行业 / 题材 / 情绪四类问题，模型只在给定的数据快照上写作，不引入外部新闻；
- 输出固定结构：裁定（看多 / 中性 / 看空 / 无法评估）、信心、关键判断（每条带证据）、驱动、风险、**可次日验证的观察信号**、数据缺口；
- 「一键今日复盘」给十段式复盘：结论 / 盘面 / 情绪 / 资金 / 板块 / 操作建议 / 昨日对照 / 明日观察 / 风险 / 数据缺口；
- 明日观察分 `prediction`（我判断会怎样）与 `trigger`（满足条件才动手），只有前者计入命中率。

### 三、自进化：让结论、技能、因子、策略都能被淘汰

这是「AI for Trade」与普通 AI 工具的分水岭。四个部件各自有明确的晋级与淘汰规则：

| 部件 | 怎么设计 | 现在 |
|---|---|---|
| **Skill 技能层** | 5 个带版本号的技能文本（如 `equity-desk@v0.1`）注入决策层，报告记录**实际加载**的版本；启动时校验数量、角色绑定与正文长度 | 已可用：加载与版本留痕；**自动进化**（历史回放 + 配对比较后晋级）规划中 |
| **记忆经验** | 推演与主题结论进全文索引，决策层自动带上同标的最近 3 条结论及事后判定，整块标注「历史结论（不是事实），不能当作今天的数字」 | 已可用 |
| **量化因子** | 49 个面板因子 + Alpha158 / 学术 / GTJA191 / 基本面导入；过「样本内 IC → 样本外 → 残差 IC」三道门才允许进面板 | 已可用：双通过 12 个，其中 8 个已晋级进面板 |
| **交易策略** | 选股条件即策略：状态机 模板 → 候选 → 观察 → 正式，按短线 / 中线 / 长线分组用不同门槛，每周全量回测排名；**失效条件必填** | 部分可用：状态机、周期分组、周度排名已上线；候选自动生成与「今日推荐」规划中 |

共同约束：技能、因子、策略的晋级门槛都是**预注册常量**，改动要单独提交并写明原因；没有失效条件的策略不允许入库。

### 四、验证闭环：每条结论都要被打分

- 推演结论可以一键落成**模拟持仓**，按面板收盘价成交、收真实费用；
- T+5 / T+20 自动判定：看多需上涨、空仓 / 否决需下跌，|收益| <1% 记中性；
- 统一**决策账本**把推演、主题、回测、成交串成一条链，能回答「这条建议后来怎样了」；
- 成本、数据健康、面板指纹都在运维视图里，可核对「这份报告用的是哪一版数据」。

### 底座：本地数据与可复现

- 8,588 个标的（A 股 + ETF）、1,345 万根日线、44 张表、约 9,600 万行，覆盖 2016-11-22 起；
- DuckDB 存面板、SQLite 存记录，单机运行，不依赖数据库服务；
- 同一份面板 + 同一组参数，重跑得到同一条净值曲线、同一份裁定、同一份报告；
- 缺数据就写「数据缺失」，不补一个看起来合理的数。

## 功能一览

左侧导航共 9 个模块：

| 模块 | 你能做什么 |
|---|---|
| **大盘** | 八大指数、涨跌家数、涨跌分布、涨跌停与封板率、两市成交额、主力/北向资金、行业资金流、申万一级/二级行业切换；右上角「一键今日复盘」 |
| **自选** | 代码 / 名称 / 拼音搜索并加自选；每行显示现价、今日、近 5 日、**自添加以来**的涨跌幅（加入时冻结基准价） |
| **全市场** | A 股 / ETF / 指数 / 港股指数四类浏览、搜索、排序；指数可点开看日 / 周 / 月 K |
| **推演** | 选一只票，跑完整的 AI 多智能体推演：7 位分析师、多空辩论、交易员给目标价与止损、三方风控、负责人裁定，全程流式输出 |
| **主题** | 一句话研究大盘 / 行业 / 题材 / 情绪，得到带数据快照的结构化备忘；也可生成当日「十段式复盘」 |
| **策略回测** | 三个 tab：**选股**（自然语言 → 53 个字段的全市场筛选）、**回测**（把这份条件当策略跑历史）、**策略库**（状态机 + 周期分组 + 周度排名） |
| **模拟持仓** | 按推演裁定建仓的虚拟账户：持仓、现金、净值曲线、成交流水、T+5 / T+20 复盘与命中率 |
| **因子** | 49 个面板因子 + 外部因子导入（Alpha158 / 学术 / GTJA191 / 基本面），算 IC / ICIR / 分层 / 样本外 / 残差 IC |
| **运维** | 统一决策账本（推演 / 主题 / 回测 / 成交一条链）、token 成本台账、数据健康与一键补数、面板指纹、记忆索引 |

### 个股详情

点任意股票（自选、热榜、选股结果）进入详情页：报价与涨跌幅、**分时 / 日 K / 周 K / 月 K**（支持 3 月 / 6 月 / 1 年 / 3 年 / 全部）、MA5/10/20/60、MACD / RSI / BOLL、基本面快照、因子快照、历史推演记录，以及一键跳到推演模块。

### 关于 AI 结论的几个约定

- **目标价与止损由模型给，百分比不由模型算**：期望收益、下行风险、赔率都由代码按收盘价计算，避免「目标价 1650、预期上涨 10%」这类自相矛盾；
- **置信度是把握程度，不是涨跌概率**：分析师给 `confidence`、交易员与风控给 `conviction`（0–100）；把「说 70% 把握对了几成」做成分档校准（命中率 / Brier）还在完善中；
- **历史结论会带上，但标明「不是事实」**：决策层能看到同标的最近 3 次结论及其事后判定，只能对照、不能当今天的数字。

## 快速开始

> 只是使用者？**不需要安装任何东西**，直接看 [USAGE.md](USAGE.md) 的网站使用指南。
> 下面是自己部署一份的步骤。

### 前置条件

- Windows 10/11（macOS / Linux 亦可）、**Python 3.11+**、**Node.js 20+**
- 磁盘约 **6 GB**（市场面板 5.16 GB + 数据库与缓存）
- 一个 DeepSeek API Key（不填也能用行情与选股，AI 功能会提示不可用）
- 可选：Tushare Pro token（有 token 才能下全量十年历史；没有就用新浪，约 4 年）

### 1. 后端（约 3 分钟）

```powershell
cd PersonalTrading

python -m venv .venv
.venv\Scripts\Activate.ps1        # macOS / Linux: source .venv/bin/activate

pip install -r backend/requirements.txt
copy .env.example .env            # macOS / Linux: cp .env.example .env
```

编辑 `.env`，至少填一项：

```dotenv
PERSONALTRADING_DEEPSEEK_API_KEY=sk-...
```

### 2. 首次初始化数据

```powershell
# 不填 Tushare token 也能跑：日历 + 列表 + 当日全市场截面 + 增量历史（新浪，约 4 年）
python scripts/sync_market.py all

# 有 Tushare token：全量回填十年历史（可中断，重跑自动续传；受每日配额限制，可能要跨天）
python scripts/sync_market.py plan --years 10
python scripts/sync_market.py backfill --years 10
```

### 3. 启动后端

```powershell
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8010
# 或：scripts\start_backend.ps1
```

打开 <http://127.0.0.1:8010/docs> 能看到接口文档即成功。

### 4. 启动前端

```powershell
cd frontend
npm install
npm run dev
# 或：scripts\start_frontend.ps1
```

打开 <http://127.0.0.1:5173>。

### 5. 五分钟上手

1. 左侧「自选」→ 搜索 `000001` 或「平安银行」→ 加入自选；
2. 点这一行进入详情：看分时 / K 线 / 指标 / 基本面；
3. 点「开始推演」，等 2–3 分钟，读一份完整报告（含目标价、止损、仓位、决策体检）；
4. 「策略回测」→ 选股 tab 输入「市盈率低于30、ROE大于15%、20日主力净流入为正」→ 结果右上角「用这些条件回测」；
5. 「运维」→ 数据健康，确认各表最新日期正常。

| 场景 | 调用次数 | tokens | 耗时 |

| 多智能体推演（2 轮辩论） | 18 | 约 65k | 约 2.5 分钟 |
| 主题研究 / 行业备忘 | 1–2 | 约 1.2 万 | 30–90 秒 |
| 一键今日复盘 | 1 | 约 1.6 万 | 30–90 秒 |

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Python 3.11、FastAPI、httpx、SQLite（标准库 `sqlite3`） |
| 市场面板 | DuckDB（全市场日线 / 复权因子 / 交易日历，列存 + 本地文件） |
| 前端 | Vue 3、TypeScript、Vite 5、ECharts 5 |
| 行情与财务 | 新浪财经、东方财富公开接口、Tushare Pro（可选）、AKShare（交易日历） |
| 模型 | DeepSeek OpenAI 兼容接口（默认 `deepseek-flash`） |
| 存储 | `data/personaltrading.db`（自选 / 笔记 / 决策记录）+ `data/market.duckdb`（市场面板） |
