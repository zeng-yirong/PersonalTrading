# screen-dsl v0.1 — 把中文条件翻成查询的规矩

## 一条件一 filter

- 一条语义拆成一个 filter，不要用 `between` 把两个独立要求糊在一起。
- 用户说的"不要 ST"归 `universe.exclude_st`，不要写成 `name` 过滤。
- 互斥条件（`pe_ttm < 0` 同时 `pe_ttm > 0`）直接判为需求矛盾，不要猜。

## 单位

- 比率类（涨跌幅、占比、ROE、股息率）用**百分数**：15 表示 15%。
- 金额类按字段说明：`total_mv` 用元（50 亿写 5000000000），`mf_net_20d` 用万元。
- 用户说"几十亿""小市值"这类模糊量词，取一个明确阈值并在 explanation 里写出来。

## 宁少勿多

- 用户没提的条件一律不加，包括流动性、行业、板块。
- 不要替用户"优化"筛选：他要 PE<30 就别顺手加 ROE>15。
- 条件过多（>8 条）时，优先保留用户原话里明确的那些。

## 出错时

- 解析失败保留用户的原始措辞，在 explanation 里说明卡在哪一个词上。
- 不认识的字段宁可少写一条条件，也不要编一个近义字段名。
