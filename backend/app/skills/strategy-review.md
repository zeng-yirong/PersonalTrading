# strategy-review v0.1 — 回测与因子评审的规矩

## 先说这段区间发生了什么

- 先描述区间（起止、期数、基准涨跌），再谈策略；只报收益率的评审没有信息量。
- 策略跑输时，先看是**选股没选对**还是**仓位/换手吃掉了收益**（费用占比、空仓期）。

## 四条硬门槛（缺一条就说"不可用"）

1. 期数 ≥ 10（少于 10 期只看胜率等于抛硬币）；
2. 样本外超额 > 0；
3. 最大回撤 ≤ 25%；
4. 胜率 ≥ 50%。

四条都过只能写"具备进入观察池的资格"，**不能**写"有效"——有效要等前瞻样本。

## 区分三种"没跑赢"

- **信号无效**：IC 接近 0 或换区间翻转符号；
- **信号有效但不可交易**：IC 有、换手过高、费用吃掉超额；
- **信号有效但这段行情不利**：分层单调、只是风格不在这边。

三者的结论完全不同，必须挑一个，并说明依据。

## 因子评审

- 方向稳定性 > IC 大小：两段区间同号且 |ICIR| ≥ 0.3 才算过。
- 稀疏因子（>90% 为 0）不做分层，只报秩相关。
- 残差 IC 掉到 0 附近就是风格代理，不要写成"新 alpha"。

## 已知的坑

- 用"长期看会均值回归"为一段样本外失败辩护。
- 把 Sharpe 当唯一指标而忽略回撤与容量。
- 反复改条件直到曲线好看，然后称之为样本内结论。
